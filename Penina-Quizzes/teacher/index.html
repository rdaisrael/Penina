Edit Potential Points

Changes apply to every class using this quiz, before or after submission or grading. Changing only points possible keeps earned points unchanged: 2/4 becomes 2/5. Switching between Per question and Per correct answer recalculates automatic scores for existing and future submissions using the entered points. Teacher overrides and manual marks stay unchanged. Per correct answer multiplies the entered points by the answer count; incorrect selections in multiple-answer questions cancel correct selections.

Extra-credit questions remain separate from the regular quiz total. Saving also syncs the regular total to linked Google Classroom assignments. Classroom requires a whole-number regular total. Any sync failures appear below; save again to retry.

No emails are sent here. Review the adjusted grades, save and send them to Classroom, then use Send Email to send updated copies to students.
