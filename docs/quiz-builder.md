# PP Quiz builder

Open `/Penina-Quizzes/builder/` from **Build a quiz** on the Penina home page. Sign in with the registered Google teacher account through Teacher tools. The account owns its own library.

Create a quiz title and a 1–1,000 minute time limit or **No time limit**, then add written answer, multiple choice, multiple answers, fill-in-the-blanks, or ordering questions. Each question has a point value and reading direction. For blanks, insert `___`, update the blanks, and select the answer for each position. Repeated answers are allowed for blanks. Ordering uses each item once; position 1 starts at the selected reading-direction edge. Written questions have optional teacher-only model answers. Other question types default to all-or-nothing scoring per question, with optional points per correct response.

**Add question with previous choices** creates a new question using the last question’s choices, type, points, scoring settings, extra-credit setting, and reading direction. The question text and correct answers start blank, and focus moves to the new question. It is available when the last question has choices and the quiz is editable. Choices are copied independently, so editing the new question does not change the previous one. The existing per-question **Duplicate** still copies the full question and answer key.

**Save draft** stores the draft across devices. Choose **Load draft** at the top of the builder or beside **Save draft** to open the saved-draft picker. It refreshes the drafts for your connected Google teacher account; select **Load draft →** on a quiz to resume editing. The **My quizzes** sidebar also offers **Load draft →** for drafts and **View quiz →** for published quizzes. Loading another quiz asks before discarding unsaved changes. Unsaved edits are held on the page and a navigation warning protects them; there is no automatic draft save. **Student preview** is practice only and sends no answers. **Publish quiz** freezes a validated snapshot, then opens the way to teacher tools. It does not post an assignment to students. Choose a class and create a Classroom draft, then review and assign it in Classroom. Duplicate a published quiz for changes or a retake; it receives a new ID and separate assignment/submissions.

Students use the existing Google enrollment checks, immutable attempts, server-verified identities, browser answer recovery, and timed quiz flow. Teachers review only quizzes they authored, correct written work in whole-point increments, or half-point increments for questions with **Allow half credit** checked, export CSV, and send completed grades to the linked Classroom assignment. Existing imported quizzes retain their pages and grading rules.

## Implementation and verification

`quiz-builder-model.js` validates question definitions, removes keys from student responses, and grades custom quizzes. `quiz-builder.js` stores encrypted owner-scoped drafts and immutable published snapshots in the existing Blob store. The account handler resolves published custom quiz IDs and creates class-specific assignment URLs. `quiz-custom-submissions.js` scopes attempts, responses, and correction records to each published quiz. All new operations share `/api/game-scores`, so no extra serverless function is added.

No new environment variables or Google permissions are needed. Existing quiz storage encryption secrets must remain stable. Questions and model answers are never embedded in public static files. New quizzes appear in the author's library; existing code-based imported quizzes remain accessible through the original teacher tools.

Run `node --test tests/*.test.js`. The new tests exercise schema validation, all five types, repeated gaps, exact grading, teacher-only writes, cross-origin rejection, owner isolation, encrypted storage, immutable publishing, dynamic assignment links, hidden answer keys, enrollment denial, one submission, corrections/grade transfer, and OAuth return paths. Browser verification uses a local in-memory Blob/Classroom simulator; real cloud persistence and Google Classroom integration need a deployed smoke test.

## Timing, review checkpoint, and class results

A null duration means no deadline, not a very long timer. Students see **No time limit** and must submit manually. Timed quizzes continue to expire normally.

In the builder, **Review checkpoint** selects the question before which the warning page appears (question 2 or later), with an editable message. The checkpoint is not scored or included in the question count. Before confirming, students can return to any earlier question. Confirmation saves and locks the entire preceding section. Each subsequent **Lock answer & next** saves and locks that answer. The final page submits all answers. Published checkpoint settings are immutable like the questions.

Immutable encrypted progress records on the server enforce sequential locks. Reloads and retries restore the same progress; editing browser values or using a stale tab cannot overwrite locked answers or skip the checkpoint. The timer continues on the checkpoint page. At expiry, unfinished work can still submit, preserving any answers already locked. Unlimited quizzes still enforce forward-only navigation.

Teacher tools include a **Results for class** selector and **Load roster & results** refresh. A current paginated Google Classroom roster is matched by verified Google user ID and class ID to student attempts and submissions. Statuses are Not assigned, Not started, In progress, Submitted, or Time expired · not submitted. Teacher practice is excluded. Rosters use names available under the existing roster permission, without requesting additional email scope. A failed roster fetch reports an error rather than showing everyone as not started. Results are snapshots; refresh to see new attempts or submissions.

Question summaries show counts and percentages out of all submissions in the selected results, with separate full-credit, zero-credit, partial-credit, and awaiting-correction columns. Non-submitters do not enter that denominator; former class members' submissions remain in class results. Percentages display a dash for no submissions. Saving a correction refreshes the on-page summary. Automatic questions that award partial credit also show a breakdown by matching pair, blank, ordering position, or multiple-answer choice, with green correct and red wrong counts and percentages. These use all selected submissions and compare original answers with the answer key; blank responses are wrong. Matching distractor rows without an answer are omitted. For multiple-answer choices, selecting a correct answer or leaving a distractor unselected is correct. Teacher point overrides affect whole-question totals only. Written questions and typed blanks have no per-part breakdown. All-classes results aggregate submissions only; select a class to get its full roster.

**Allow half credit** appears beside each question’s points and defaults to unchecked. Unchecked questions use whole-number point values and teacher marks. Checking it enables 0.5-point increments for both. Unchecking it while the point value is fractional requires changing that value to a whole number before saving. The scoring-mode radio buttons separately control whether automatic credit is per question or per correct response.

**Points apply to:** each question offers **Pts. per total question** (default) and **Pts. per correct response** beside the point value. Per-question scoring awards the configured value only for a complete correct automatic answer. Per-response scoring awards that value for each correct blank, correctly positioned ordering item, or correct selected answer. Multiple-answer questions require exactly the answer-key count of selections (or fewer on timer expiry), preventing selecting every option for full credit. Written and single-choice questions each have one response. Half-point increments are still separately opt-in. Builder totals, student point labels, grading, report totals, and Classroom maximum points use the resulting question maximum. Published quiz scoring can be revised through Edit Potential Points as described below. Partial automatic results show “Partly correct” after submission.

## Vocabulary question options

Matching questions pair each teacher-entered word or definition with an answer from a word bank. Use **Add word or distractor** to add extra choices and select the correct answer for each item. Choices may be reused. Unused choices are distractors and never earn credit. Scoring can apply to the complete question or each correct match.

Fill-in-the-blank questions use `___` for each blank. **Use a word bank** defaults to checked and supports any number of distractors within the 50-choice limit. Uncheck it for typed answers, then enter the answer key for each blank. All typed answers, including blanks without a word bank, require teacher correction. They are never graded automatically, even if they exactly match the model answer or are blank on timeout or optional extra-credit questions. Until the teacher awards points they show blue “Needs correction”; correct is green, incorrect red, and partial credit remains separate. Existing saved text-question marks retain their question positions. Existing published blank questions retain their word banks and grading behavior.

## Generate a quiz from a vocabulary list

Choose **Generate quiz from lists** beside **New quiz** at the top of the builder. This opens the list generator; if a list is already loaded, it jumps to **Choose your quiz**, where the **Generate quiz** button appears above the settings. You can use saved wordlists and knowledge lists, or upload CSV/TSV/text/Markdown, paste a Markdown table from chat, or paste two columns copied from a spreadsheet: word and definition. Markdown alignment separator rows are ignored. Only recognized column labels are removed as a header, so a vocabulary entry above a separator stays in the list. A header row is optional. CSV definitions containing commas must be quoted. Lists support 2–50 entries (10–15 recommended), with 500 characters per word or definition and a 100 KB import limit.

The editable table has one distractor column: English-only distractors for Hebrew terms, and Hebrew-only distractors for English terms. The correct translation must use that same opposite language. **Generate distractors** suggests three distractors per word. Regenerate one row or all rows; replacement of existing edits requires confirmation. Generation failures leave the existing table untouched. Suggestions need teacher review for semantic correctness. Manual distractors can also be entered, one per line (up to ten in each cell). The table is the exclusive source of distractors when generating a quiz: single-term questions use only that row, and matching banks combine only the rows being matched. Other vocabulary definitions are not borrowed as wrong answers. Generation never invents or fills in extra distractors; empty required banks prompt the teacher to fill the table first.

**Use the suggested question count** is on by default. The count updates as vocabulary, selected formats, and draft questions change. It chooses the fewest questions that cover the most remaining words, while including every selected format with counts differing by at most one. Matching uses 4–6 terms in one language per question; ordering uses 2–4. The coverage preview distinguishes question count from words tested, lists existing and planned question numbers per word, and reports untested words or existing repeats. If the selected formats cannot cover all words, change the formats or add vocabulary. Turn off the suggested count to enter a count manually; a count requiring repeated words is blocked with guidance.

Choose **Generate quiz** with the **Add questions for untested words** action to check the entire current draft, including unsaved edits and older questions. Each word is tested only once across generated formats and batches. Existing prompts, unambiguous approved correct answers, matching pairs, ordering items, and saved generation targets identify words already tested; words appearing only as distractors do not count. Rephrasing a generated question or switching its format does not create an unused word. The generator uses exact normalized terms and saved targets, not AI inference of arbitrary paraphrases in manually written questions. Removing a question makes its words available again unless another question still tests them. The same translation pair imported in both directions is treated as one fact.

The **Replace previously generated questions** action changes the button to **Regenerate quiz** and replaces questions marked by this generator after confirmation, preserving manually added questions and excluding their words from generation. Older questions without generation metadata remain in the draft and are included in coverage; remove those manually if they should be replaced. A review checkpoint attached to a retained manual question follows that question; a checkpoint on a removed question, or one that moves to the first question, is cleared.

Written questions ask for the opposite-language translation; teachers grade them. Ordering sorts vocabulary alphabetically. Distractor suggestions use the existing server-only OpenAI adapter. Answer keys and choice banks are constructed from teacher-reviewed vocabulary. Blanks ask for the opposite-language translation. Mixed-language lists are supported; each matching group uses terms in one language. Multiple-answer questions ask about exactly one term and use its main definition plus teacher-entered Additional correct answers as the answer key. They require at least two distinct approved answers; slash-separated definitions are not automatically split. Distractors remain incorrect choices, never additional correct answers. Terms without additional correct answers can be used by the other selected formats. Generation rejects answers or distractors in the wrong language. Legacy extra-word lists remain stored for compatibility but are not displayed or used for new questions.

Generation runs in batches of at most ten. No questions are added until all batches finish successfully. Add mode appends to the current draft; replace mode changes only the generated set. Both respect the 100-question draft limit. Failed or cancelled generation preserves the complete original draft, including its checkpoint. Teachers can name the quiz, edit generated questions/answer keys/points, or add more questions in the regular builder. Save, publish, and Google Classroom assignment use the existing workflow; generation does not publish or assign anything.

Vocabulary tables and settings save in the encrypted owner-scoped draft, survive reload and duplication, and remain out of public published snapshots. Generated question targets and provenance survive save/load and quiz duplication and are omitted from student question responses. Table edits affect future generation, not existing questions. The existing OPENAI_API_KEY and configured model settings are used. Automated tests stub the AI service; live semantic quality and Google Classroom assignment should receive a deployed smoke check.


### Editing potential points after publication

Assigned custom quiz cards offer **Edit Potential Points**. The quiz author can change each question’s denominator (0.5–5,000, in half-point steps) before students start, during attempts, or after submission and grading. Changes apply to all classes using that quiz. When only the numerical denominator changes, all earned points—including automatic answer-key awards, manual marks, and overrides—remain unchanged. Extra-credit denominators stay separate from the regular total. Future submissions use the original answer-key awards with the revised denominator.

Edits are encrypted, append-only revisions separate from the published question snapshot. Stale editors cannot overwrite a newer revision, and stale correction forms must reload before saving or sending. Grades previously sent to Classroom or students are no longer marked current after a denominator edit. Saving automatically syncs the regular total to linked Classroom assignments, including drafts. Failed updates are reported by class and can be retried by saving again. Fractional regular totals remain saved in Penina but cannot sync until adjusted to a whole number. Review and send updated grades, then use **Send Email** for updated corrected tests. Saving potential points never sends email automatically. Earlier built-in/imported quizzes do not expose this editor.

The builder and student preview load the latest potential-point revision. Duplicating a quiz carries those totals into new scoring settings: fully correct answers earn the revised maximum. For matching and word-bank blanks that previously scored per response, a revised total is divided proportionally across responses, with partial scores rounded to two decimal places. The original quiz and its earned marks are unchanged. Correctness labels on unoverridden automatic answers use the answer-key scoring maximum, while displayed score denominators use current potential points. Teacher overrides and manual scores retain their score-based labels.


The potential-points editor also offers **Per question** and **Per correct answer** for every question. Switching modes recalculates automatic scores for saved answers and future submissions using the entered value; teacher overrides and manual marks remain unchanged. Per-answer values multiply by the response count for the denominator. In revised per-answer scoring, matching, blanks, and ordering earn credit per correct position; multiple-answer questions earn credit for correct selections minus incorrect selections, with a zero minimum. Numerical denominator edits without a mode change still preserve automatic awards. Mode changes use the same revision and stale-grade safeguards as denominator edits.


Student Google sign-in requests permission to turn in the student’s own Classroom work. After Penina saves a student’s answers, it turns in the linked assignment using that student’s authorization. Teacher practice does not turn in work. Already turned-in or returned work is left as-is on retries. If permission or Classroom is unavailable, the quiz remains saved and the receipt directs the student to mark it done in Classroom. Teacher grade transfer continues to save only a draft grade; the teacher releases it with Return in Classroom.


### Reusing saved vocabulary

The vocabulary panel offers a downloadable two-column CSV template (Word, Definition). Replace the examples with one pair per line. Imports support commas, tabs, and two-column Markdown tables. Quote CSV definitions containing commas. Excel workbooks must be exported as CSV or their two relevant columns copied and pasted.

Use **Show / refresh my lists** to choose published wordlists and knowledge lists from vocabulary webpages owned by the signed-in teacher. Review one or more selected lists, resolve conflicting definitions, then load them into the vocabulary table. Identical terms are combined. Missing translations are reported. Saved Gamify distractors are reused only when they still match the term and definition; no AI generation runs during import. Loading replaces the current table after confirmation and leaves existing questions and source lists unchanged. Save the draft to retain the imported table.

**Generate missing distractors** fills rows with no distractors without replacing reviewed choices. Regenerate row/all remains available for explicit replacement. Combined imports support up to 50 unique words and 10 distractors per word.

### Picture questions
Choose **Picture question**, upload a JPG, PNG, or WebP, and enter your question and model answer. Click the picture to place an optional location marker; arrow keys move it when the picture is focused. Clear marker removes it. Add a picture description for accessibility without revealing the answer. Students submit a written response for teacher grading. Pictures are resized to at most 1,200 pixels and stored with the quiz; drafts, duplicates, previews, student review, and teacher correction retain the picture and marker. Uploads are limited to 15 MB before resizing, 250,000 characters per stored image and 2,500,000 per quiz.

Use **Add marker** above the picture to create up to 20 numbered markers within one question. Choose **Marker to move**, then click the picture or use its arrow keys to position that marker. **Remove selected marker** removes its model answer and renumbers the remaining markers. **Student answers** selects one shared written answer or one answer per marker; separate model answers are retained when switching between layouts. **Pts. per total question** uses the points value once; **Pts. per correct response** multiplies it by the number of requested answers. Teachers award the written question’s score manually. Marker positions, answer layout, and model answers survive save, reload, and duplication.

Existing quizzes with a separate question for each marker retain **Add marker question**. Each marker is a separate written question with its own prompt, model answer, points, and teacher correction. All markers appear on each question, with the current one highlighted. Moving a marker or replacing the picture updates the whole group. Removing a question removes its marker and renumbers the remaining markers; duplicating an individual question creates an independent single-marker copy.

### Generate from knowledge lists or mixed lists

The saved-list chooser accepts either list type or a mixture. Knowledge questions retain their original question/answer wording, pictures and location markers; they do not use the vocabulary translation rules. English and Hebrew saved distractor banks are retained in the draft. Select the bank during import or switch it in the review table. Missing banks are reported for teacher completion or explicit generation; importing and generating questions never invents missing distractors.

Pictures appear in generated individual questions, the builder, student preview, student quiz and review. Unpictured knowledge questions can be grouped for matching. Pictured questions remain individual; ordering is vocabulary-only. Coverage distinguishes separate knowledge cards even when their question text is identical, and retains their identities through save/load and duplication. Existing vocabulary-only quiz behavior is unchanged.
