# Teacher entrance

Open `/Penina-Quizzes/teacher/` from Teacher tools on the Penina home page. Teachers use Sign in with Google with their registered school account. After Google verifies the identity, the server looks up that email in the teacher registry and assigns its teacher number. Unregistered accounts cannot enter. No Penina password is needed for this entrance. Existing Google subject IDs continue to own quizzes, assignments, and submissions.

The home page has two choices: **Write & assign quizzes** opens the library/builder and class assignment controls; **Correct quizzes** lists the signed-in teacher’s stored Classroom assignments with a class filter. Classroom drafts are identified. Imported quizzes remain accessible in both areas. Review links select the relevant class; older imported results are filtered by the stored class ID.

Assignment pages can create/open a Classroom draft and explicitly publish it to students. Publishing verifies the stored assignment, teacher membership, active class, developer ownership, and maximum points. Review pages retain corrections, CSV export, and server-calculated grade transfer. User 1’s authenticated session authorizes imported quiz reports without repeated grade passwords. Vocabulary publishing passwords are unchanged.

The new entrance uses the existing Google OAuth scopes and encrypted 30-day teacher session cookie (student sessions remain 24 hours). It requires no new environment variables. Normal sign-in reuses saved Classroom access without forcing consent. Missing offline access triggers one consent retry; Reconnect Classroom is available for revoked access. Google can still require renewed consent. The server verifier is deliberately under the existing blocked `/lib/quiz*` route. Rotate the verifier to change the teacher account password; never place plaintext credentials in static files.

Validation: `node --test tests/*.test.js`. Local browser preview uses simulated Classroom responses; real Google consent, assignment publication, and grade transfer must be checked after deployment with the teacher account.

Teacher numbers: David Israel owns number 1. The main homepage includes a number directory and assignment form at the bottom, visible only after David signs in. The public Teacher sign-in link opens Teacher tools; after signing in, use Penina home to return to user management. Assigning requires his signed-in session and the separate assignment code. New teacher credentials are salted scrypt verifiers in encrypted Blob records; their Google callback is bound to the registered email and carries their teacher number. Existing numbers cannot be overwritten.

Vocabulary creation requires the exact, case-sensitive owner creation code. New publishing passwords must start with a positive teacher number and a hyphen. Signed-in teachers receive only their own pages; student study links remain public. Built-in pages derive ownership from their configured publishing passwords. Older custom pages using the original number-1 grade passwords are recognized; other legacy pages record ownership when their password is successfully used. The builder also provides “Add an older webpage to my list” for linking an existing page before publishing again. Teacher names and assignments cannot be inferred from old password verifiers and must be entered by David.
